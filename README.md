# The Last 5 Days – online (Activity 1 + 1.1)

A single-page web app for **Activity 1 (The Last 5 Days)** and **Activity 1.1 (The Performance Aftermath)**.
No server, no build step, no libraries: one `index.html` file that runs on **GitHub Pages**.

## Publish it on GitHub (5 minutes)
1. On github.com create a **new repository** (public), for example `last5days`.
2. Click **Add file → Upload files**, drag in **`index.html`** (and `.nojekyll`), then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment* choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
4. Wait 1–2 minutes. Your site is at `https://YOUR-USERNAME.github.io/last5days/`.
   (GitHub Pages on a private repository needs a paid plan, so keep the repository public.)

To change anything later, upload a new `index.html` to the same repository.

## Run a session
**You (facilitator)** open the site and click **Facilitator**.
1. *Setup and group link*: choose the number of groups and a **session code** (default `LAST5`). Copy the **group link** and send it to the groups (chat, QR code, or write it on the board).
2. **Open the next day**: pick the day (Day 5 first). A **4-digit code** appears: read it out. Groups type it to unlock that day.
3. Each group opens the link, picks its **group number**, enters the code, chooses **one action** and presses **Lock in our choice**. They see the effect on the **Target only**.
4. Collect the choices: each group has a **code** such as `G3-BCA` (Copy button on its screen). Paste the codes into **Paste group codes**, or type the letters in the grid, or edit any cell yourself.
5. **Capacity, Trust and Continuity start appearing from Day 4**, after the Day 5 decision (change this in Setup). On a group's screen they appear when it reaches that day; on the projector view they appear when you open that day.
6. Click **Projector view** to show the room only what it is allowed to see. Switch back to see all numbers and **Real Target** (the average of Target, Capacity and Trust).
7. After Day 1 choose **Final reveal**: everything is visible. Open **Compare (1.1)** for the debrief screen.
8. Groups continue to **Aftermath (1.1)**: the chart of their decisions, WHAT? SO WHAT? NOW WHAT?, and Keep / Stop / Start (one item each). **Copy our answers** puts their text on the clipboard.

If you fix a group's choice in the grid, give the group its new code and they press **Sync code** on their screen.

## Good to know
- There is **no live connection between devices**: that is why the codes exist. Everything is saved in the browser of the device in use (localStorage); **Reset session** clears the facilitator side, **Leave** clears a group's device.
- Round codes can be switched off in Setup (groups can then move on without a code).
- The hidden effects are part of the page code, so this is a classroom tool, not a secure exam. Group devices only show the group pages.
- You can test it locally by double-clicking `index.html`.
